# PlotTwist — Study for the Plot.

PlotTwist 是面向大学生的互动学习游戏：通过掌握英文词汇推动原创悬疑爽文，通过自己的课堂笔记生成可玩的调查与配对挑战。项目服务于 HKBU × AWS Kiro Hackathon 的 UN SDG 4（优质教育）主题。现有代码可直接在 Kiro IDE 中打开继续开发；本项目没有伪造 Kiro 使用记录。

## 运行

需要 Node.js **22.13+**（`pdfjs-dist` 6 的要求）。

```bash
npm install
npm run dev
```

打开终端给出的本地地址，通常是 `http://localhost:5173/`。无需后端、账号、数据库或 API Key。

```bash
npm run build
npm test
npm run test:e2e
```

`test:e2e` 自动启动临时 Vite 服务。Windows 默认使用系统 Edge；其他系统请先执行 `npx playwright install chromium`，或设置 `PLAYWRIGHT_BROWSER_EXECUTABLE` 为浏览器可执行文件路径。截图保存在本地忽略目录 `artifacts/`。

## V2 功能

- **Story Map**：六章相连的章节地图，显示锁定、可进入、进行中和已通关状态。通关章节可重读、复习本章词汇并重做测试。
- **原创互动主线**：六章、每章三个词汇互动节点、五道章节题。第四章含玩家明确选择带来的不同场景；第一、四章也有答错后的陷阱与补救内容。
- **七本演示词书**：IELTS、CET-6、HKDSE English、CEFR A1/A2/B1/B2，各有 20 个不同等级的示例词。词汇实际进入阅读、词卡和测试。均为学习演示词表，**不是官方完整词库**。
- **章节挑战**：五题至少答对四题才解锁下一章。低分显示错题并可换序重试。每章首次通关得 100 XP；重玩不会重复领取章节奖励。进度仍保存在原有 `plottwist-progress-v1` localStorage 键中，旧 IELTS/CET-6 进度自动补齐新字段。
- **三语界面与剧情**：English、香港粤语书面语、简体中文；语言选择持久化。英文目标词保持英文。用户上传的原始笔记不会自动翻译。
- **朗读与音效**：浏览器 SpeechSynthesis 朗读当前段落，可暂停、继续、调节语速及静音；英文词卡可发音。系统有粤语语音时选用粤语，否则显示回退提示。正确、错误、奖励和解锁使用本地合成的短音效；减少动态效果设置会关闭这些音效。
- **Notes to Game**：粘贴、上传或拖放 `.pdf` / `.txt` / `.md`。PDF 在浏览器本地使用 `pdfjs-dist` 提取多页文字，内容可编辑预览。解析出至少三条 `Term: Definition` 后，可选择 **Knowledge Adventure** 答题调查，或 **Matching Challenge** 概念配对。题目答案只取自用户笔记。
- **学习档案**：各词书独立的章节、词汇和 XP，错词列表，以及当前词书的重置操作。

## 演示路线

1. 首页 → 故事模式 → 选词书 → 章节地图 → 第一章。尝试朗读与词卡。
2. 完成三个填空，章节挑战答对至少四题，解锁第二章。
3. 回地图重读第一章、重做测试，确认 XP 不会重复获取；刷新后仍保留通关状态。
4. 切换 A1、B1、DSE 等词书，再进入章节，观察英文目标词与难度变化。
5. 切换 English / 廣東話 / 简体中文，观察界面与剧情切换。
6. 笔记闯关 → 填示例笔记，或拖入文字型 PDF → 检查可编辑提取文本 → 选择两种不同玩法。

## 已知限制

- 故事只有一条六章主线，另有短分支；校园悬疑尚未制作。词书是小型演示数据，章节 5/6 有设计为复习用的重复目标词。
- PDF 仅能读取内嵌文字，**不支持扫描图片 OCR**。笔记解析采用本地规则，主要支持每行 `概念: 解释`，没有调用 LLM。PDF 版式复杂时需要在预览框手工整理。
- 浏览器语音质量与可用语言取决于设备；找不到粤语语音时会明确提示回退。朗读默认依赖浏览器能力，自动化测试只能验证控件，不等同于人工听音质检。
- 笔记原文和当次游戏局面不持久化；笔记 XP 会保存，重复游玩可再次获得笔记 XP。故事章节 XP 只发一次。
- 进度仅存于当前浏览器设备，清理站点数据会丢失记录。没有云同步。
