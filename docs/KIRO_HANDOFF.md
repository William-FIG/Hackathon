# Kiro 交接（V2）

## 真实完成状态

本次升级在现有 PlotTwist 项目内完成，沿用 React/TypeScript/Vite/Tailwind、原有进度键、故事组件和规则解析。已实现六章原创剧情、七套演示词书、Story Map、章节重访及无重复章节 XP、三语界面/剧情、浏览器朗读、音效、本地 PDF 文字提取、Knowledge Adventure 与 Matching Challenge。代码并非由 Kiro 开发，目前没有 Kiro 使用记录。

## 尚未实现或部分实现

- 校园悬疑第二故事、无限剧情树、完整官方词库、CEFR C1。
- PDF 扫描图像 OCR、自由格式笔记的语义理解、真正 LLM 生成。
- 语音依赖用户浏览器和操作系统。没有录制配音文件；粤语可用性由本机语音决定。
- 笔记局面不跨刷新保存；笔记 XP 可重复获取。章节 XP 已限制为每章一次。
- 登录与云同步、正式学习成效研究、全面无障碍审计。

## 推荐下一步

1. 建立剧情/词书 JSON schema 与内容编辑校验，提升后续章节的可维护性。
2. 增加笔记解析后的概念编辑步骤、对长篇自由格式资料的安全支持；需要 AI 时使用服务端代理且保留本地回退。
3. 为笔记游戏加入合理的 XP 上限、间隔复习与概念掌握度；评估真实学习效果。
4. 为粤语朗读准备授权配音或验证过的设备语音方案；继续测试键盘导航、屏幕阅读器与小屏交互。
5. 若希望进入比赛正式技术叙事，下一阶段在 Kiro IDE 中开发并如实记录所用 Kiro 功能。

## 建议测试

- 每种词书完整跑通六章；关键剧情选择和返回地图后的段落位置。
- 在旧 V1 localStorage 数据下升级并确认 IELTS/CET-6 成绩保留。
- 粤语语音可用/不可用时的标识、暂停和离开章节后的停止。
- 不同版式多页 PDF、扫描 PDF、损坏 PDF、超过大小限制，以及概念抽取结果编辑。
- 两种游戏的错题、重试、触屏配对和无障碍操作。

## 当前验证

`npm run build`、`npm test`、`npm run test:e2e`。后者覆盖六章通关、章节重做 XP 不重复、地图、语言切换、PDF 拖放提取、两种游戏、手机布局；浏览器自动化不能验证实际扬声器音质。
