# PlotTwist 产品规格（V2）

## 用户与问题

目标用户是备考 IELTS、CET-6、HKDSE、按 CEFR 分级学习英文，或需要复习课程笔记的学生。纯背词和反复看笔记缺乏推进感；PlotTwist 把词汇理解、知识回忆设计为故事和小游戏的推进条件。

## SDG 4 关联

项目尝试提升优质教育中的参与度和自主学习体验。浏览器本地运行、无需账号和付费服务，降低体验门槛；用户可用自己的笔记生成练习。当前原型没有进行对照研究，不能声称已经证实记忆效果提升。

## 核心体验

1. **故事地图**：六个相连节点展示进度，锁定节点说明解锁要求，已通关节点可以重读、复习和重测。
2. **互动叙事**：原创《逆袭：被开除的实习生》，六章连贯剧情，答题推动段落；第一/四章有陷阱与补救；第四章还让玩家决定如何应对盟友背叛，展示两段不同场景。
3. **分级词汇**：七本不同数据的演示词书。每章五个目标词，三个互动填空与五题测试。80% 为章节通关门槛。
4. **声音与语言**：朗读当前剧情、英语词汇发音、短音效；中简、香港粤语书面语和英语界面及剧情。
5. **笔记游戏**：本地提取 PDF 文本或读取 TXT/MD，再从原文解析概念。Knowledge Adventure 是逐题调查；Matching Challenge 是双列配对与连击，两者玩法不同。
6. **学习档案**：本地保存每本词书的学习、掌握、错题、章节与 XP。

## 创新点

- 知识是剧情关卡的钥匙，而不是阅读后的独立小测。
- 原创故事与词书数据分离，同一剧情可随词书替换真正的目标词。
- 章节地图使进度具有游戏空间感，已通关内容仍然可反复学习。
- 用户上传的知识材料直接决定游戏题目，不臆造来源之外的答案。
- 规则解析与本地 PDF 提取让核心演示在无云服务条件下运行。

## 主要路径

首页 → 选词书 → 地图 → 阅读/填空/剧情选择 → 五题挑战 → 80% 通关与 XP → 新章节 → 回地图复习。

首页 → 粘贴/上传/拖放笔记 → 可编辑预览 → 选择游戏 → 调查问答或概念配对 → 成绩与待复习内容。

## 演示边界

七本词书各 20 个示例词，不代表官方完整考试或 CEFR 词库；故事只有主线和有限短分支；PDF 不做 OCR；笔记内容不会由 LLM 生成或翻译。
